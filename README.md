# 蜀门甩二

四川单副升级扑克游戏：**一副 54 张牌**，四人分两队。你坐南家，与北家的 AI 队友合作，对抗东西两位 AI。游戏完全在浏览器中运行，无需联网服务、注册账号或安装依赖。

## 立刻开始

- **Mac 本地游玩：** 下载并解压整个项目，双击根目录的 `index.html` 或 `打开游戏.command`。MacBook Air M3 的 Safari、Chrome 等现代浏览器均可运行。
- **其他电脑本地游玩：** 下载并解压整个项目，双击根目录的 `index.html`。请保留 `dist/` 文件夹及其中全部文件。
- **GitHub Pages 在线游玩：** 仓库开启 Pages 后，点开仓库主页显示的 Pages 地址即可进入游戏。

GitHub 仓库若从 `main` 分支的根目录启用 GitHub Pages，仓库的 Pages 链接也会直接进入游戏。根目录的 `index.html` 负责跳转到 `dist/index.html`，因此本地双击和 GitHub Pages 使用同一份游戏文件。无需构建步骤。

## 本版规则

- 每人 12 张，留 6 张底牌。庄家拿底后埋回 6 张。
- 双方各自从级牌 2 开始。J 为 11，Q 为 12，K 为 13，A 为 14。庄家用当前级牌确定主花色。除打 A 的局外，大小王、四张当前级牌、四张 7 和主花色牌都是主牌。
- 打 A 时没有主花色，**仅四张 A 和两张大小王是主牌**。
- 5 计 5 分，10 与 K 各计 10 分，全副共 100 分。**只计算闲家抓到的分**；庄家赢得的分牌算跑掉，不记入抓分。
- 闲家抓分达到 45 分时只换庄，不升级。低于 45 分则庄家方继续坐庄，按跑掉的分数升级：以 45 分为基数，每多跑出完整的 10 分升一级。例如闲家只抓到 25 分，庄家跑掉 75 分，下局从 2 升至 5。
- 闲家赢得末墩时，埋底分牌按双倍计入闲家抓分。庄家赢得末墩时，底分算跑掉，不另计分。
- 有首出类别时必须跟足；没有才能垫牌或用主牌杀。首家可单出，也可选择同类别多张甩牌。
- “同”由玩家手中的四张同点数牌组成。仅前三轮可由首家打出。跟家有“同”必须跟“同”；没有时要出最大的四张主牌，主牌不足再以最大的副牌补足。“同”大于任何非“同”牌，点数大的“同”压点数小的“同”。
- 任一方先把级牌升到 A，即赢得整场比赛。

游戏内点击右上角的“规”可随时查看规则。对局和级牌进度会保存在当前浏览器本机，浏览器不允许存储时仍可正常完成当前对局。

## 项目结构

```text
index.html          本地和 GitHub Pages 入口
dist/index.html     游戏界面
dist/styles.css     样式
dist/rules.js       规则与升级计算
dist/app.js         发牌、出牌和 AI
打开游戏.command     macOS 双击入口
tests/rules.test.js 规则边界测试
```

开发者可运行 `node --test tests/rules.test.js` 检查关键规则。游戏本身不依赖 Node.js。
